# 生成内容安全策略 v1

## 目标

生成内容安全分为两道独立边界：生成前只给模型允许引用的事实，生成后验证模型是否忠实使用事实。提示词是辅助约束，不是安全边界；确定性校验负责最终放行或阻断。

## 生成前策略

`ContentSafetyService.prepare_evidence()` 只保留：

- 有稳定 `source_id` 的来源；
- 披露级别为 `public`、`familiar`、`close` 或 `trusted` 的来源；
- 当前渠道已选择并附带归属、状态的结构化来源。

聊天提示词明确区分 UNA 自己事件、NPC 近况、共同事件、意向和建议。朋友圈和日记只接收已经筛选的生活摘要，不接收 `private_thought`、候选评分、决策上下文等内部字段。

## 生成后规则

当前确定性规则包括：

| 代码 | 含义 | 处理 |
|---|---|---|
| `internal_marker_leak` | 输出含内部字段或评分标记 | 高风险阻断 |
| `private_thought_leak` | 输出逐字包含内部私人想法 | 高风险阻断，审计不回显原文 |
| `unfinished_source_as_completed` | 把 active/deferred/pending 来源描述成已完成 | 阻断 |
| `npc_experience_claimed_by_una` | UNA 第一人称冒领 NPC 经历 | 阻断 |
| `author_source_mismatch` | 朋友圈作者不是来源事件参与者 | 阻断 |
| `content_not_grounded` | 朋友圈或日记与提供来源没有可解释文本关联 | 阻断 |
| `source_not_found` | 来源不存在或不属于当前用户 | 阻断 |
| `unsupported_source_type` | 来源类型没有权威解析策略 | 阻断 |
| `source_metadata_mismatch` | 证据中的人物、状态、时间或披露级别与权威表不一致 | 阻断 |
| `source_not_disclosable` | 权威来源为私密或未知披露级别 | 高风险阻断 |
| `image_prompt_not_grounded` | 图片提示词没有携带可验证场景事实 | 改用安全空白页提示 |

文本关联使用规范化中文二元片段覆盖率，并辅以角色显示名命中。它追求可复现、可测试，不替代未来的语义事实核验。

## 渠道降级

每个渠道有固定降级文本：

- 聊天：承认刚才没有准确表达，不再继续错误细节。
- 朋友圈：说明片段尚未整理好，不发布新的事实声称。
- 日记：保留空白，不补写未经验证的经历。

降级文本不调用 LLM，避免安全失败后再次生成新的不确定内容。原始错误文本不落库；落库的是降级文本、`blocked` 状态和问题代码。

带生活证据的聊天使用回复级原子放行：模型仍可流式生成，但全部相关文字会先在服务端组合校验，通过后才进入文字和语音投递。日记图片提示词会附带已经验证的场景事实；提示词无法对齐时不调用原提示，而使用“柔光下的空白日记页”安全提示，并记录 `image_prompt_fallback`。

## 确定性评估门禁

`ContentSafetyEvaluator` 在临时 SQLite 世界中运行固定语料，不读取或写入用户数据。语料覆盖安全的 UNA 第一人称、正确 NPC 转述、未完成打算，以及人物冒领、状态错误、作者不匹配、来源篡改、来源缺失、内部字段和无依据日记。

开发接口：`POST /api/life/acceptance/safety-evaluate`。

门禁同时要求：

- 安全样例放行率 100%；
- 危险样例召回率 100%；
- 每个危险样例命中预期稳定问题码；
- 评估结果不返回原始内容文本。

## 已知边界

- 当前规则不做通用事实蕴含判断；大幅改写可能被视为未使用来源。
- 回复级缓冲已覆盖跨片段组合错误，但当前仍是词法和状态规则，不是通用语义蕴含模型。
- 私人想法检测针对明确文本重合，不宣称覆盖同义转述泄漏。
- 图片只在日记正文安全后生成；当前不验证图片画面与事件证据的一致性。

## 后续增强顺序

1. 引入“事实声明—来源事实”结构化抽取，覆盖同义改写和隐含因果。
2. 在现有来源权威解析基础上，为不同意向状态增加更细的完成语义词表。
3. 把固定确定性语料扩展为经人工标注的真实生成样本集。
4. 当前只校验图片提示词；像素级多模态一致性仍需独立视觉模型。
