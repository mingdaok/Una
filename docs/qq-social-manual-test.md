# QQ 群友升级：简单测试

## 先启动

1. 在运行 UNA 的窗口按 Ctrl+C，然后重新运行：

   ```powershell
   cd D:\ai\Una\.worktrees\qq-chatbot\Una
   .\scripts\start-qq.ps1
   ```

2. 保持 NapCat 开着。打开 http://127.0.0.1:8001 ，按 Ctrl+F5 刷新。
3. 用管理员账号登录，打开「QQ 连接」。应看到「群友能力」，里面有群行为、聊天记录、插话诊断、表情库、后台任务。
4. 如果没有管理区域，检查 `.qq.env` 的 `UNA_QQ_ADMIN_IDS` 是否是当前站内账号 ID；修改后重启。不是填 QQ 号。
5. 先启用白名单测试群。「收集本群表情」「允许偶尔主动发语音」默认关闭，不必一开始打开。

## 逐项测

| 要测什么 | 怎么做 | 正常结果 |
|---|---|---|
| 不 @ 插话 | 打开无需 @，两个人连续聊一个话题 | 她可能插话，也可能沉默；插话诊断显示原因。默认至少隔 3 分钟、每小时最多 6 次 |
| 普通群友发言 | 分别普通聊天、@ 她提问、让她发表情 | 默认直接发言，不逐条引用或 @；只有需明确回应旧消息/交错话题时才可能引用 |
| 认对人 | A 说喜欢猫，B 说喜欢狗，再 @ 问谁喜欢什么 | 不把 A 和 B 混为一人 |
| 不 @ 看图 | 开启群自主参与，不 @ 发送图片和问题；正常/95% 测试模式分别测 | 决定参与时先看图再回复；仍可能沉默，不要求每条必回 |
| 引用图片 | 发图片，再引用图片询问，不要求 @ | 处理被引用的图；多个候选不明确时询问 |
| 先图后问 | 发一张图，再说“这是什么”“看看这个” | 使用同一人近期图片；两个人各发图时不串人 |
| 接续看图 | 引用图片问“这张图里是啥”，再说“说话” | 接续自己的最近图片问题；已换话题则不附带旧图 |
| 选择旧消息 | 两人分别发图，让机器人自主选择接话 | 看的是被选中的消息图片，不是最后一人的图片 |
| 补聊天记录 | 聊天记录 → 补取最近 100 条 → 后台任务 | 显示实际获取/新增数量，不对旧消息补发回复；协议端可能返回不足 100 条 |
| 发表情 | 表情库选择测试群，上传自有 PNG/GIF，填写含义 | 图片可预览，状态可使用。聊相应情境时可能配图，也允许不用图 |
| 空图库 | 先不上传任何图片，正常聊天 | 文字回复照常工作 |
| 自动收集 | 打开收集，群里发一张新表情 → 后台任务 → 表情库 | 先待审核；确认含义后点接收使用。默认仅本群可用 |
| 禁用表情 | 在表情库点禁用 | 后续不再发送该图；排队中的旧图片也不能发送 |
| 发语音 | @ 她说“用语音说一句晚安” | 先收到文字，再收到语音，手机可播放；合成失败不重复正文 |
| 群隔离 | 另一测试群询问前一个群的聊天/表情 | 不读取前一个群记录或专属表情 |
| 清空记录 | 聊天记录 → 清空本群上下文 → 确认 | 本群旧上下文和排队回复失效 |
| 重启与断线 | 聊天中断开 NapCat，再连接 | 不连续补发过时插话；回执不明不会自动重复发送 |

## 出问题先看这里

- 完全不回复：QQ 连接是否已连接、测试群是否启用，再看插话诊断。
- 图片下载失败：新代码自动回退真实 DNS；查看是 DNS、下载 HTTP、证书还是模型阶段错误。下载仍发生在电脑上；模型说“空框”不能作为下载错误证据。
- 没有语音：后台任务查看 TTS 错误，确认现有 TTS 服务正在运行且 ffmpeg/ffprobe 可用。
- 表情一直待审核：填写含义并点接收使用；自动接收是另一个独立开关。
- 不要把每条都回复当作通过标准，自主聊天本来就允许沉默。

实际 PNG、GIF、手机语音播放、多人插话质量尚需按此表验证。自动化测试使用模拟协议和模型，不能代替手机验证。


## 审核修复后，先测这 6 项

先停止旧 UNA，运行 ` .\scripts\start-qq.ps1`，网页按 Ctrl+F5。

1. **限时插话**：QQ 连接 → 群友能力 → 群行为 → “测试 30 分钟（95%）”。群里聊天，应偶尔回复。点“结束本群测试”，恢复正常频率；不是每条消息都保证回复。
2. **停用有效**：向机器人提问后立即在网页关闭该群。还没提交发送的回复应取消；已经提交给 QQ 的消息不能保证撤回。重新开启群后再发新问题。
3. **撤回和历史**：让她发一条回复，撤回那条消息，再问“刚才谁说了什么”。撤回内容不应再成为有效上下文。连续点两次“补取最近 100 条”，聊天记录不应重复增加同一消息。
4. **表情删除**：删除一张表情，刷新页面不能再预览或接收该条素材；其他群使用的同图不应被一同删除。
5. **语音状态**：私聊说“用语音回复你好”。文字应先到；QQ 连接里的“我的语音任务”可查看合成及投递状态。回执不明不自动重发。手机是否能播放需要实际确认。
6. **诊断**：群友能力 → 插话诊断查看失败阶段；表情库看“语义索引”或“文字检索（降级）”。没有嵌入服务时仍能聊天、按描述选图。

补充：发送“不要插话”后，自主插话暂停 60 秒；直接 @ 仍可提问。机器人被禁言时停止发送。重启不会补发超过 60 秒的旧自主回复，私聊/直接回复超过 300 秒也会作废。

真实验收记录：图片 [ ]、GIF [ ]、手机语音播放 [ ]、撤回 [ ]、关闭群取消 [ ]、重连 [ ]。这些项目本轮均未代替你在真实 QQ 中操作。
