# NPC 世界检查器 v1

## 目标

NPC 世界检查器是开发和调参入口，用来确认小满、知夏、阿岚等角色是否真的拥有彼此独立、可持续演进的生活。它与用户看到的温暖生活页分离，不改变任何模拟结果，也不会向前端暴露私人想法或内部评分。

## 入口

1. 进入 UNA 的生活页。
2. 点击顶部的“打开 NPC 世界检查”按钮。
3. 在左侧切换 NPC；移动端人物列表会改为横向排列。
4. 点击左上角返回按钮回到生活页。

检查器先加载启用的朋友角色列表，只在选中人物后读取其详细历史。快速连续切换人物时，过期请求不会覆盖当前人物的数据。

## 四个检查面板

### 状态与日程

- 当前活动、地点和心情
- 精力、饥饿、压力、社交需要、独处需要
- 已生成的未来日程
- 当前仍在进行的独立意图

### 事件与互动

- 固定日程产生的生活事件
- 自主决策产生的独立行动
- NPC 之间的共同互动
- 冲突、修复等互动在当前人物视角下的安全解释

### 关系网络

- 对方角色和关系层级
- 接近度、熟悉、好感、信任、紧张指标
- 当前允许披露的信息层级

这里用于调试关系演进；聊天接口仍会依据关系层级过滤实际可说内容。

### 意图与建议

- 人物形成过的意图及状态变化
- 用户建议的接受、调整、延后或拒绝结果
- 建议是否转化成了人物自己的意图

### 质量评估与内容安全

- “质量评估”在隔离临时世界中比较多种子生活密度、重复、互动和意图结果。
- “内容审计”只读检查当前用户的朋友圈、日记和聊天证据。
- “运行安全门禁”在临时数据库执行固定内容安全语料，展示危险召回率、安全放行率和稳定问题码漏检数，不读取当前用户内容。

## 手动验收清单

### 基础交互

- [ ] 打开检查器后默认选中第一个启用的 NPC。
- [ ] 切换小满、知夏、阿岚时，名字、状态和历史同步变化。
- [ ] 快速来回切换人物，不出现上一人物的数据覆盖当前人物。
- [ ] 刷新按钮重新读取当前人物，刷新期间按钮不可重复触发。
- [ ] 四个标签都能切换，空数据展示明确的空状态。
- [ ] 返回后 UNA 生活页原有状态仍然保留。

### 数据一致性

- [ ] 每个 NPC 的状态数值均在 0–100 范围内。
- [ ] 日程按时间显示，并包含摘要、时间窗、地点和状态。
- [ ] 事件来源能区分“固定日程”“自主行动”“共同互动”。
- [ ] 同一共同互动在双方视角中均可找到，参与者和解释合理。
- [ ] 冲突后关系紧张度上升；修复后紧张度下降或信任有所恢复。
- [ ] 用户建议结果与人物意图记录能够对应。

### 隐私边界

- [ ] 页面不显示 `private_thought`、内部候选分数或原始决策理由。
- [ ] 共同互动只展示服务端提供的安全视角字段。
- [ ] 浏览器请求失败时只显示可理解的错误和“重试”，不泄露服务端堆栈。

## 涉及接口

- `GET /api/life/actors?role=friend`
- `GET /api/life/actors/{actor_id}/life`
- `GET /api/life/actors/{actor_id}/events`
- `GET /api/life/actors/{actor_id}/interactions`
- `GET /api/life/actors/{actor_id}/relationships`
- `GET /api/life/actors/{actor_id}/intentions`
- `GET /api/life/actors/{actor_id}/suggestions`

详细数据以服务端返回的用户安全 DTO 为准。检查器不直接读取数据库表，也不应新增只为展示内部隐私数据的接口。

## 当前边界

- v1 是只读观察工具，不提供修改状态、强制触发事件或重置世界的按钮。
- 当前不展示跨日统计曲线和完整世界拓扑。
- 模拟时间推进仍由既有结算入口负责，检查器只读取结算后的结果。

统一验收能力已经在 `npc-acceptance-tools-v1.md` 中实现和说明，包括虚拟时间推进、固定场景种子、双重确认重置和生产环境路由隔离。
