# NPC 内容生成质量审计 v1

## 目标

内容审计用于检查已经生成的朋友圈、日记和聊天文本是否忠实引用生活世界，同时避免暴露角色的私人想法或内部决策信息。

它是只读工具，不生成新内容、不修改历史记录，也不会自动删除或改写发现问题的内容。接口只在 `UNA_ENV=development` 时注册。

## 使用方法

1. 打开“NPC 世界检查”。
2. 切换到“内容审计”。
3. 点击“审计最近内容”。

默认范围：

- 最近 50 条 AI 朋友圈
- 最近 30 篇日记
- 最近 100 条 AI 聊天消息

审计始终按当前登录用户过滤，客户端不能指定其他用户。

## 检查项目

### 来源可追溯性

对于标记为生活事件生成的朋友圈和日记，检查：

- 是否包含 `source_event_ids`
- 来源事件是否存在并属于当前用户
- 内容作者是否为事件参与者

缺少来源或引用不存在事件会记录为错误。

### 来源文本关联度

计算内容与来源事件摘要的中文二元片段覆盖率。关联度过低会提示内容可能补充了来源里不存在的事实。

这是可解释的文本规则，不是语义模型。合理改写可能得到较低分，因此它只用于定位需要人工复查的内容。

### 时间连续性

朋友圈会比较：

- `life_world_time`
- 来源事件结束时间
- 内容发布时间

日记会比较 `life_world_date` 与来源事件日期。明显不一致时记录提示。

### 隐私边界

审计器会在服务端比较用户可见内容与生活事件中的私人想法，但只返回命中数量和问题代码，不返回私人想法原文。

只要一条内容疑似命中私人想法，该内容对应的所有问题摘录都会统一替换为：

```text
[高风险内容片段已隐藏]
```

同时检查以下内部标记是否进入用户内容：

- `private_thought`
- `candidate_scores`
- `decision_context`
- `disclosure_level`
- 内部评分、候选分数等调试表达

### 重复表达

在同一作者、同一内容渠道内，使用中文三元片段 Jaccard 相似度检查近重复内容。相似度达到 78% 时记录重复问题。

### 角色口吻规则

读取集中角色档案中的 `speaking_style`，检查目前可稳定量化的两项：

- `emoji_level: none` 的角色是否使用 emoji
- `sentence_length` 与实际平均句长是否明显冲突

“温柔”“克制”“直接”等语气暂不通过关键词武断判断，后续可加入模型评审或人工标注集。

### 聊天生活引用

新聊天消息通过 `content_evidence_json` 保存本轮允许引用和实际使用的来源。审计会验证 `used_source_ids` 是否存在、是否属于当前用户，以及文本关联和时间连续性，并计入 `traceable_life_chat_count`。

迁移前的旧聊天没有证据包。发现旧消息包含 NPC 名称和生活叙述时，仍记录 `chat_source_untraceable`，但不影响消息读取。

## 风险等级

- `high`：疑似私人想法或内部字段泄漏。所有摘录强制隐藏。
- `error`：来源缺失、来源不存在或作者与事件参与者不一致。
- `warning`：时间、表达关联、重复、口吻或聊天可追溯性问题。

自动规则只用于定位，不直接删除内容。高风险项应优先人工复查。

## 指标解释

- 来源可追溯率：成功找到全部来源事件的生活内容比例。
- 来源文本关联度：内容与来源摘要的平均片段覆盖率。
- 时间一致率：世界时间与来源事件时间一致的比例。
- 口吻规则一致率：通过当前量化口吻规则的内容比例。
- 重复内容率：近重复内容对数除以审计内容数，用于版本间比较。
- 隐私疑似泄漏：与内部私人想法逐字重合的内容数量。
- 聊天生活引用：规则识别到的 NPC 生活叙述数量。
- 可追溯聊天生活引用：具有可验证结构化来源的 NPC 生活叙述数量。

## 开发接口

`POST /api/life/acceptance/content-audit`

请求示例：

```json
{
  "post_limit": 50,
  "diary_limit": 30,
  "chat_limit": 100
}
```

生产环境不会注册该路由，前端也不会展示内容审计入口。

同一面板还可以调用 `POST /api/life/acceptance/safety-evaluate` 运行隔离的固定安全回归语料。它与本接口职责不同：内容审计检查已经生成的用户内容，安全门禁检查规则本身是否出现漏放或误阻断。

## 当前边界与后续工作

- 不使用大模型判断文风，避免不可复现的审计结果。
- 不检测图片内容与事件是否一致。
- 不自动修复历史内容。
- 迁移前聊天仍无法补造准确来源，只能保留兼容提示。
- 当前文本关联使用确定性片段规则，不等同于完整语义事实核验。
