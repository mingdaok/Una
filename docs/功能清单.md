- [x] 后端生成结构化 `live2d_action_v2` 动作事件。
- [x] WebSocket 将动作事件与文字回复分离传输。
- [x] 前端动作编译器根据模型、意图、强度和随机种子生成自由参数轨迹。
- [x] 用户发送消息后立即触发 `local_micro_reaction` 细微倾听反应。
- [x] 动作参数不接管嘴部参数，语音口型保持最高优先级。
- [x] 新旧动作执行路径分离，自由动作不再读取旧版 `params`。

- [x] 单个动作采样器异常时自动丢弃当前动作，呼吸、眨眼和口型 Ticker 继续运行。
- [x] 动作时长缺失或非法时使用 800 毫秒安全默认值。
- [x] 增加 Live2D 控制器回归测试，覆盖无 `params`、采样异常和时长缺失。
- [x] 完成前端生产构建并同步到 `backend/static/mobile`。
- [ ] 在真实浏览器中连续发送多条消息，人工确认模型持续呼吸、眨眼、说话并执行自由动作。

## 本次修复的验收标准

1. 发送文字后，控制台不再出现 `Cannot read properties of undefined (reading 'direction')`。
2. AI 开始回复前可以看到轻微倾听反应。
3. AI 回复过程中自由动作、文字和语音能够同时工作。
4. 回复结束后模型继续呼吸和自动眨眼，不停留在最后一帧。
5. 连续发送多条消息后，Live2D Ticker 不停止。
