# ==================================
# 部署服务器 特别注意事项：
# ==================================
# 1. 如果你在云端租用的是 【PyTorch 镜像】，它系统里自带了 PyTorch, torchvision, torchaudio。
#    因此你直接 pip install -r requirements.txt 即可，不要在这里写 torch 以免发生冲突！
#
# 2. 如果是用空的纯净系统或者 Miniconda，你需要手动安装 GPU 版 PyTorch，命令如下：
#    pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
#
# 3. 本项目依赖 FFmpeg，必须在 Linux 系统层安装：
#    Ubuntu/Debian 系统执行: apt-get update && apt-get install ffmpeg -y
#
# 4. 如果使用 GPT-SoVITS 语音合成，请保持你的 GPT-SoVITS 服务独立运行。
